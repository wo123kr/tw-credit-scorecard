# 점검 보고서 쓰는 법

순서: 한 줄 요약(배치 · 건수 · PSI 수준 · 기준선 미만 비중) → 경고(없으면 「없음」) → 원인 피처 → 라벨이 있으면 성과 · 구간별 연체율 → 집단별 점검 → 권고(재학습 검토 · 수집 확인 · 보정 점검 중 해당하는 것만) → 참고.

- 숫자마다 비교 대상을 붙인다(참조 대비, 학습 구간 대비). 숫자 하나만 두지 않는다
- 「우연」「정상」으로 단정하지 않는다. 기준을 넘었는지 아닌지를 쓴다
- 권고는 담당자가 할 행동으로 쓴다(「수집 팀에 한도 값 결측 원인 확인 요청」). 모형이 결정하는 문장은 쓰지 않는다
- 모의 배치면 모의라고 적는다
